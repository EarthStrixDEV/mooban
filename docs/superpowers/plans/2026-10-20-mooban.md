**Goal:** สร้าง Mooban (โซเชียลขนาดหย่อม: โพสต์/รูป/ไลก์/คอมเมนต์/แกลเลอรี/SSE) ให้ทำงานเหมือนกันทุกประการบน 4 stack (Apache+PHP, Nginx+PHP-FPM, Node/Express, Python/Flask) พร้อมหน้าเว็บ SPA ชุดเดียว เครื่องมือทดสอบ และแบบฟอร์มผล

## Global Constraints

- โครงโฟลเดอร์ตาม Spec §13: `shared/public/{index.html,app.js,style.css,robots.txt,sample.jpg,js/…}`, `shared/schema.sql`, `php/{public/{api.php,.htaccess,media/.htaccess},src/,config.sample.php}`, `nginx/nginx-snippet.conf`, `node/{app.js,package.json,.env.sample,src/}`, `python/{app.py,passenger_wsgi.py,requirements.txt,.env.sample,mooban/}`, `tools/{sse-load.js,make-test-images.py}`, `RESULTS.md`
- ไฟล์หน้าเว็บ byte-identical ทุก stack; หน้าเว็บไม่มี framework, ไม่มี build step, ไม่มี inline `<script>`/`<style>`/`style=""`/`on*=`, ไม่มี CDN/ฟอนต์ภายนอก, ไม่มี `eval`/`innerHTML` กับข้อมูลผู้ใช้
- HTML ทุกหน้า: `Content-Security-Policy: default-src 'self'; img-src 'self' data:` + `X-Content-Type-Options: nosniff`; ทุก response: `X-Robots-Tag: noindex`; ทุก `/api/*`: `X-Stack: <APP_STACK>` + `Server-Timing: app;dur=<ms>`; ไม่เปิด CORS
- Config ทุก stack (Spec §10): `DB_HOST DB_NAME DB_USER DB_PASS APP_STACK TEST_TOKEN MEDIA_DIR CACHE_DIR PORT MAX_UPLOAD_BYTES=10485760 MAX_PIXELS=24000000 SSE_POLL_MS=1000 SSE_MAX_SECONDS=60 MAX_STREAMS_PER_IP=10` + **เพิ่ม** `PUBLIC_DIR` (Node/Python: โฟลเดอร์ `shared/public`) — config อยู่นอก document root, ห้าม commit ค่าจริง
- DB: ทุก connection `SET time_zone = '+00:00'`, prepared statement ทุก query, token เก็บเป็น SHA-256 hex
- ทุกการเขียนที่มี event: transaction เดียว, `INSERT INTO events` เป็นคำสั่งสุดท้ายก่อน COMMIT; หลัง event id ที่ `id % 100 == 0` ลบ events ที่ `created_at < NOW(3) - INTERVAL 1 HOUR`
- ความยาวทุกฟิลด์นับเป็น Unicode code point หลัง trim และเก็บค่าที่ trim แล้ว
- Media: `MEDIA_DIR/<media_key>/{display,thumb}.{webp|jpg}`, `media_key` = hex สุ่ม 16 ตัว, header `Cache-Control: public, max-age=31536000, immutable`, `X-Content-Type-Options: nosniff`, รองรับ ETag/Last-Modified → 304, ไม่มี directory listing, ห้ามรันสคริปต์
- UI copy ภาษาไทยตาม DESIGN-mooban.md ทุกตัวอักษร; token ตาม `design-handoff/tokens/mooban.css` (ห้ามเขียน hex ใน component ยกเว้นกลุ่มที่ DESIGN §7.2 ระบุ); system font stack DESIGN §2.1

### สัญญาที่สเปคไม่ได้ระบุ — แผนนี้กำหนดให้ (ทุก stack ต้องเหมือนกัน)

- **รูปเวลา:** ISO-8601 UTC ไม่มีมิลลิวินาที `YYYY-MM-DDTHH:MM:SSZ`
- **User object** (POST /api/users `user`, GET /api/me): `{id, handle, display_name, created_at}`
- **GET /api/users/{handle}** 200: `{handle, display_name, created_at, post_count, image_count}` (handle ใน path แปลงเป็นพิมพ์เล็กก่อนค้น)
- **Image ในโพสต์:** `{id, thumb_url, display_url, width, height, alt}` (ตามตัวอย่าง Spec §5)
- **Image ใน GET /api/images / PATCH response:** `{id, thumb_url, display_url, width, height, format, bytes_thumb, bytes_display, alt, created_at, author:{handle, display_name}}`; POST /api/images 201 = shape เดียวกัน + `processing_ms`
- **Like PUT/DELETE 200:** `{post_id, like_count, liked_by_me}`; event `like.changed` ส่ง **เฉพาะเมื่อแถวถูกเพิ่ม/ลบจริง**
- **Pagination:** `limit`, `before`, `after` ต้องเป็นจำนวนเต็มบวก และ `limit` อยู่ใน 1..max ไม่งั้น 400 `bad_params`; `user` ที่ไม่มีอยู่ → `{"data":[],"next_*":null}`
- **ลำดับตรวจของ endpoint เขียน:** 401 (token) → 404 (resource) → 403 (owner) → 429 (rate limit, นับทุกครั้งที่ผ่านขั้นก่อนหน้า) → 400 (JSON) → 422 (validation). Signup: 429 → 400 → 422 → 409
- **Rate limit:** `window_start` = นาทีปัจจุบัน (UTC, ตัดวินาที), `retry_after` = วินาทีที่เหลือถึงสิ้นนาที ปัดขึ้น ขั้นต่ำ 1, header `Retry-After` เท่ากัน; `/api/limited` ใช้ bucket `ip:{ip}:limited` limit 10 + `X-RateLimit-Limit`/`X-RateLimit-Remaining`
- **ข้อความ validation (`fields`)**:

| field | เงื่อนไข | ข้อความ |
|---|---|---|
| handle | ผิดรูปแบบ/ความยาว | `ต้องยาว 3–20 ตัวอักษร ใช้ได้เฉพาะ a-z, 0-9 และ _` |
| display_name | ว่างหรือ > 50 | `ต้องยาว 1–50 ตัวอักษร` |
| body (โพสต์) | > 280 | `ยาวเกิน 280 ตัวอักษร` |
| body (โพสต์) | ว่างและไม่มีรูป | `ต้องมีข้อความหรือรูป` |
| body (คอมเมนต์) | ว่าง หรือ > 280 | `ต้องยาว 1–280 ตัวอักษร` |
| image_id | ไม่มี / ไม่ใช่ของผู้เขียน | `ไม่พบรูปนี้` |
| image_id | ผูกกับโพสต์อื่นแล้ว | `รูปนี้ถูกใช้กับโพสต์อื่นแล้ว` |
| alt | > 200 | `ยาวเกิน 200 ตัวอักษร` |

- **App cache:** `GET /api/stats` เก็บที่ `CACHE_DIR/stats.json` 10 วินาที (Spec Mooban §8); ตัวนับ hit/miss ของ `/api/cache-stats` ย้ายไป `CACHE_DIR/cache-counters.json` (Tabby ใช้ชื่อ `stats.json` ซ้ำกัน); ทุกการเขียนสำเร็จ (users/posts/likes/comments/images/seed) ลบ `stats.json`; `DELETE /api/cache` ลบทั้งสองไฟล์ ตอบ 204
- **โควตารูป:** นับเฉพาะ images ของ user ที่ handle ไม่ขึ้นต้น `seed_`
- **Test token บนหน้า /test:** เก็บในตัวแปรหน่วยความจำเท่านั้น (Spec §12 ชนะ DESIGN §6.8 ที่เสนอ sessionStorage)
- **Dev ports:** mysql 3307, apache 8081, nginx 8082, node 8083, python 8084; DB ชื่อ `mb_apache mb_nginx mb_node mb_python`; `TEST_TOKEN=dev-test-token-0123456789abcd`
